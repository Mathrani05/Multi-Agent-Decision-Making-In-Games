## Project Overview
This project implements a multi-agent game environment using:
- Minimax
- Alpha-Beta Pruning
- Expectiminimax
- Gemini/API-based AI agents

The project evaluates the algorithms based on execution time,
node evaluations, success rate, and scalability.
